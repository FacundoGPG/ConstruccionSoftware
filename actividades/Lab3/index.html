Reflexión

¿Cuál es la diferencia entre padding y margin?
El padding es el espacio interno de un elemento, es decir, la distancia entre el contenido y su borde. En cambio, el margin es el espacio externo, que separa un elemento de otros elementos alrededor.

¿Por qué se recomienda usar box-sizing: border-box?
Porque hace que el tamaño total de un elemento incluya el padding y el border, lo que facilita controlar el diseño y evita que los elementos crezcan más de lo esperado.

¿Qué significa diseñar con enfoque mobile-first?
Significa diseñar primero para dispositivos móviles (pantallas pequeñas) y luego adaptar el diseño para pantallas más grandes usando media queries.

¿En qué situaciones preferirías rem sobre px?
Se prefiere usar rem cuando se quiere que los tamaños sean adaptables y consistentes en diferentes dispositivos, especialmente en textos y espacios. En cambio, px se usa cuando se necesita un tamaño fijo, como en bordes o detalles específicos.
