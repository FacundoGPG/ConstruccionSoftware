Elementos que se utilizan en desarrollo Web:

1. ¿Por qué es una buena práctica usar JavaScript para validar inputs antes de enviarlos al servidor?

Es una buena práctica porque mejora la experiencia del usuario al dar retroalimentación inmediata sin necesidad de recargar la página. También reduce la carga en el servidor, ya que evita enviar datos incorrectos o incompletos.

2. ¿Cómo puedes saltarte la seguridad de validaciones hechas con JavaScript?

Las validaciones con JavaScript pueden saltarse desactivando JavaScript en el navegador, modificando el código desde las herramientas de desarrollador, o enviando directamente peticiones al servidor mediante herramientas como Postman o scripts personalizados.

3. Si se pueden saltar las validaciones de JavaScript, ¿por qué sigue siendo una buena práctica?

Porque aunque no son seguras por sí solas, sirven como una primera capa de validación para mejorar la experiencia del usuario y reducir errores. Sin embargo, siempre deben complementarse con validaciones del lado del servidor, que son las que realmente garantizan la seguridad.
